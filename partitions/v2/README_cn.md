# 分区表 v2 版本

本版本相比 v1 引入了重大改进，新增了 `assets` 分区以支持网络可加载的内容，并针对不同 flash 容量优化了分区布局。

## 相对 v1 的关键变化

### 主要改进
1. **新增 Assets 分区**：新增 `assets` 分区用于存放网络可加载的内容
2. **替换 Model 分区**：旧的 `model` 分区（960KB）被更大的 `assets` 分区取代
3. **优化 App 分区**：缩小应用分区大小以容纳 assets
4. **增强灵活性**：支持动态内容更新，无需重新烧录

### Assets 分区特性
`assets` 分区存储以下内容：
- **唤醒词模型**：可定制的唤醒词模型，支持从网络加载
- **主题文件**：完整的主题系统，包括：
  - 字体（文本字体和图标字体）
  - 音效和声音文件
  - 背景图片和 UI 元素
  - 自定义表情包
  - 语言配置文件
- **动态内容**：所有内容均可通过 HTTP 下载进行 OTA 更新

## 分区布局对比

### v1 布局（16MB）
- `nvs`：16KB（非易失性存储）
- `otadata`：8KB（OTA 数据）
- `phy_init`：4KB（PHY 初始化数据）
- `model`：960KB（模型存储 — 固定内容）
- `ota_0`：6MB（应用分区 0）
- `ota_1`：6MB（应用分区 1）

### v2 布局（16MB）
- `nvs`：16KB（非易失性存储）
- `otadata`：8KB（OTA 数据）
- `phy_init`：4KB（PHY 初始化数据）
- `ota_0`：4MB（应用分区 0）
- `ota_1`：4MB（应用分区 1）
- `assets`：8MB（网络可加载资源）

## 可用配置

### 8MB Flash 设备（`8m.csv`）
- `nvs`：16KB
- `otadata`：8KB
- `phy_init`：4KB
- `ota_0`：3MB
- `ota_1`：3MB
- `assets`：2MB

### 16MB Flash 设备（`16m.csv`）— 标准配置
- `nvs`：16KB
- `otadata`：8KB
- `phy_init`：4KB
- `ota_0`：4MB
- `ota_1`：4MB
- `assets`：8MB

### 16MB Flash 设备（`16m_c3.csv`）— ESP32-C3 优化版
- `nvs`：16KB
- `otadata`：8KB
- `phy_init`：4KB
- `ota_0`：4MB
- `ota_1`：4MB
- `assets`：4MB（4000K — 受可用 mmap 页数限制）

### 32MB Flash 设备（`32m.csv`）
- `nvsfactory`：200KB
- `nvs`：840KB
- `otadata`：8KB
- `phy_init`：4KB
- `ota_0`：4MB
- `ota_1`：4MB
- `assets`：16MB

## 优势

1. **动态内容管理**：用户可下载并更新唤醒词模型、主题等资源，无需重新烧录设备
2. **App 体积缩减**：应用分区经过优化，为动态内容腾出更多空间
3. **增强定制能力**：支持自定义主题、唤醒词和语言包，提升用户体验
4. **网络灵活性**：资源可独立于主应用固件进行更新
5. **更优的资源利用**：通过可配置的资源存储高效利用 flash 内存
6. **OTA 资源更新**：资源可通过 HTTP 下载进行 OTA 更新

## 技术细节

- **分区类型**：assets 分区使用 `spiffs` 子类型，兼容 SPIFFS 文件系统
- **内存映射**：assets 通过内存映射方式访问，运行时效率高
- **校验和验证**：内置完整性校验，确保资源数据有效
- **渐进式下载**：资源可分步下载并支持进度跟踪
- **回退支持**：网络更新失败时可优雅回退到默认资源

## 从 v1 迁移

从 v1 升级到 v2 时：
1. **备份重要数据**：确保旧 `model` 分区中的重要数据已备份
2. **烧录新分区表**：根据 flash 容量选择对应的 v2 分区表
3. **下载资源**：设备首次启动时会自动下载所需资源
4. **验证功能**：确保所有功能在新分区布局下正常工作

## 使用注意事项

- `assets` 分区大小因配置而异，以适配不同 flash 容量
- ESP32-C3 设备由于系统可用 mmap 页数有限，使用较小的 assets 分区（4MB）
- 32MB 设备拥有最大的 assets 分区（16MB），可存储更多内容
- 所有分区表均保持适当的对齐，以获得最佳 flash 性能
