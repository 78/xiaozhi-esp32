## 已实现

### 固件

- Aliyun 只有 Manual 与 Auto。Manual 再次单击提交，异步等待编码和发送队列排空；Auto 服务端 VAD 分轮。
- Auto 回复期间关闭语音处理和云端上行，等云端回复结束、本地解码/播放队列及 I2S DMA 尾部排空再恢复；清除旧输入帧，不把播放期间说话缓存到下一轮。
- 双击 BOOT 切换模式、取消旧会话；Listen / Speak / Standby 状态附带模式。网页不提供模式选择。
- 连接操作移出主事件循环；连接代次、回复代次、弱引用和上行代次用于隔离取消后的迟到回调。
- Waveshare 3.5B 不启用设备 AEC，保留 NSNet2。板型和引脚未更改。
- ES8311 成功读取后的 24 kHz 单声道 PCM16 在重采样和软件处理前旁路采集；Auto 播放期间保持原始采集。诊断拥塞独立记录 gap。
- 调试 hello 记录固件实际版本。扩大播放缓冲后，保持原有录音自测最大时长。

### 统一配置页

- LAN 80 端口统一小智和 Aliyun 配置；服务选项独立保留，空 Key 保留已有密钥。
- Wi-Fi 配网共用原扫描、提交和重启接口；热点主页面由项目构建规则替换，未手改 vendor 文件。
- 热点服务配置 API 使用 81 端口并限定对应跨域来源；Wi-Fi 与服务分别保存。
- 简洁卡片布局，设备信息、状态、音量、重启和折叠的高级调试配置。

### Go Debug

- 透明双向 WS 转发与有界异步录制；Authorization 不落盘。
- 记录真实握手/事件 reqid、request_id 和作用范围，保留 session / response / event ID，不虚构逐轮 reqid。
- 原始输入、云端上行、云端下行三条音轨。通过设备 boot / trace 标识显式关联独立诊断会话。
- 对话文本优先，原始事件折叠，事件详情、搜索、波形、分段 WAV、包含关联会话的导出。
- 暂停、格式、响应和样本间断分段；录制 gap、截断、未正常结束状态可见。
- 单会话默认 256 MiB、总量默认 1 GiB；达到上限停止记录。保留策略默认不删除，显式开启时只在启动时清理过期且已结束记录。
- 旧 AEC 录音读取兼容仍保留，当前页面不提供 AEC 实验流程。

### 播放中切换与取消

最终固件通过 HTTP 调用同一业务动作：先确认 Auto / listening，检测到 Auto / speaking 后切换，约 1 秒后变为 Manual / idle，再等待 4 秒仍为 idle，没有被旧回复回调重新拉回播放或监听。测试后恢复 Auto / idle。该结果不替代实体 BOOT 双击验收。
