# Xiaozhi ESP32 — MCP Tools: Управление устройством

## Что такое MCP?

**MCP (Model Context Protocol)** — это встроенный в прошивку сервер, который позволяет AI-ассистенту (серверная часть) управлять устройством через структурированные JSON-RPC вызовы. Когда ты разговариваешь с устройством, AI на сервере может вызывать «инструменты» (tools) прямо на плате.

**Это значит:** ты говоришь фразу вроде «сделай громче» или «убавь яркость экрана» — и AI сам вызывает нужную функцию на устройстве.

---

## Доступные инструменты (Tools)

### 1. `self.get_device_status`
**Что делает:** Возвращает текущий статус устройства — громкость, яркость, состояние батареи, WiFi и т.д.

**Когда вызывается:** AI вызывает это автоматически, когда ты спрашиваешь:
- «Какая сейчас громкость?»
- «Какой уровень заряда?»
- «Покажи статус»

**Параметры:** нет

---

### 2. `self.audio_speaker.set_volume`
**Что делает:** Устанавливает громкость динамика.

**Параметры:**
| Имя | Тип | Диапазон | Описание |
|-----|-----|----------|----------|
| `volume` | integer | 0–100 | Уровень громкости в процентах |

**Примеры голосовых команд:**
- «Поставь громкость на 50%»
- «Сделай тише»
- «Максимальная громкость»
- «Выключи звук» (volume=0)

**Как работает:** Вызывает `codec->SetOutputVolume(volume)` на аудиокодеке ES8311.

---

### 3. `self.screen.set_brightness`
**Что делает:** Устанавливает яркость экрана через PWM подсветку.

**Параметры:**
| Имя | Тип | Диапазон | Описание |
|-----|-----|----------|----------|
| `brightness` | integer | 0–100 | Яркость экрана в процентах |

**Примеры голосовых команд:**
- «Убавь яркость до 30%»
- «Максимальная яркость»
- «Приглуши экран»

**Как работает:** Вызывает `backlight->SetBrightness(brightness, true)` — PWM на GPIO45 (TFT_BL). Параметр `true` означает «сохранить значение» (запомнится после перезагрузки).

---

### 4. `self.screen.set_theme`
**Что делает:** Переключает тему экрана между светлой и тёмной.

**Параметры:**
| Имя | Тип | Значения | Описание |
|-----|-----|----------|----------|
| `theme` | string | `"light"` / `"dark"` | Название темы |

**Примеры голосовых команд:**
- «Включи тёмную тему»
- «Светлый режим»

> **Примечание:** Доступно только в режиме LVGL-дисплея (Default/WeChat style). В Emote-стиле (глаза робота) тема всегда тёмная.

---

### 5. `self.get_system_info` (только для пользователя)
**Что делает:** Выводит системную информацию — версия прошивки, свободная память, MAC-адрес, и т.д.

**Голосовая команда:** «Покажи системную информацию»

---

### 6. `self.reboot` (только для пользователя)
**Что делает:** Перезагружает устройство.

**Голосовая команда:** «Перезагрузись» / «Reboot»

---

### 7. `self.upgrade_firmware` (только для пользователя)
**Что делает:** Скачивает и устанавливает прошивку по URL.

**Параметры:**
| Имя | Тип | Описание |
|-----|-----|----------|
| `url` | string | URL бинарного файла прошивки |

**Голосовая команда:** «Обнови прошивку с адреса ...»

---

## Как это работает внутри

```
Пользователь говорит → Сервер AI → JSON-RPC → MCP Server на ESP32 → вызов функции
```

1. Пользователь произносит команду (например, «сделай громче»)
2. Аудио уходит на сервер, где его обрабатывает AI-модель
3. AI решает вызвать инструмент `self.audio_speaker.set_volume`
4. Сервер отправляет JSON-RPC запрос по WebSocket:
   ```json
   {
     "jsonrpc": "2.0",
     "id": 1,
     "method": "tools/call",
     "params": {
       "name": "self.audio_speaker.set_volume",
       "arguments": {"volume": 80}
     }
   }
   ```
5. MCP Server на ESP32 парсит запрос и вызывает `codec->SetOutputVolume(80)`
6. Результат отправляется обратно на сервер

## Добавление своих инструментов

Кастомные инструменты добавляются в файле платы, в методе `InitializeTools()`:

```cpp
// В freenove-esp32s3-display-2.8-lcd.cc
void InitializeTools() {
    auto& server = McpServer::GetInstance();
    server.AddTool("self.my_custom_tool",
        "Description for AI to understand when to use this tool",
        PropertyList({
            Property("param_name", kPropertyTypeInteger, 0, 100)
        }),
        [](const PropertyList& properties) -> ReturnValue {
            int value = properties["param_name"].value<int>();
            // ... действие ...
            return true;
        });
}
```

## Текущие ограничения Freenove

- **Тач-управление громкостью/яркостью:** Штатно отсутствует. Управление только голосом через MCP.
- **Device-side AEC:** Недоступен для Freenove (нет физической изоляции микрофона от динамика).
- **Камера:** Отсутствует на плате, инструмент `self.camera.take_photo` не доступен.
