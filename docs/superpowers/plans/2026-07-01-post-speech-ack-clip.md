# Post-speech acknowledgment clip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play a short random English "got it" clip ~1s after a child's speech turn ends, device-local, to cover the pre-reply latency gap — without being re-captured by the mic or firing on non-speech.

**Architecture:** On `listen.stop` (a real RMS-gated speech turn) arm a 1s `esp_timer`; its callback `Schedule()`s onto the main task, and if still listening + connected + not-error it suppresses capture (`EnableVoiceProcessing(false)`), plays a random `OGG_ACK_*`, and re-enables capture only after a tagged playback-completion marker fires (unless the real reply already took over). Clips are generated offline into `main/assets/locales/vi-VN/` and auto-embedded as `Lang::Sounds::OGG_ACK_*`.

**Tech Stack:** ESP-IDF (C++17) firmware; ESP timers; existing `AudioService` decode/playback pipeline; Python 3 + Google Cloud TTS (voice clone) + ffmpeg for asset generation; CMake asset embedding via `gen_lang.py`.

## Global Constraints

- Device is `CONFIG_LANGUAGE_VI_VN`-pinned; ack clips are **English audio** but live in `main/assets/locales/vi-VN/` (embedded byte blobs addressed by `OGG_ACK_*`). — verbatim from spec §2.
- No `robo-worker` / bridge changes. Pure firmware + assets. — spec Non-goals.
- Mic suppression during the ack MUST use `EnableVoiceProcessing(false)` (stops AFE production, `BumpUpstreamGeneration()` drops queued PCM/EOS markers), not merely skipping `SendAudio`. — spec §3.
- Re-enable capture only via a **tagged completion fired after the final `codec_->OutputData()`**, never queue-empty/`IsIdle()`. — spec §3.3.
- `ACK_DELAY_MS = 1000` (tunable constant). — spec §1.
- The ack `esp_timer` callback must `Schedule()` work onto the main task, never run `EnableVoiceProcessing`/`PlaySound` inline. — spec §1.
- Clips ≤ ~800ms so a `ResetDecoder` flush-on-reply leaves a minimal tail. — spec §1.
- Only armed in the gated config (`CONFIG_VAD_GATED_UPSTREAM`), on the EOS-marker `listen.stop` path. — spec §1.

```cpp
void AudioService::PlaySound(const std::string_view& ogg, std::function<void()> on_complete) {
    sound_complete_cb_ = std::move(on_complete);

    if (!codec_->output_enabled()) {
        esp_timer_stop(audio_power_timer_);
        esp_timer_start_periodic(audio_power_timer_, AUDIO_POWER_CHECK_INTERVAL_MS * 1000);
        codec_->EnableOutput(true);
    }

    const auto* buf = reinterpret_cast<const uint8_t*>(ogg.data());
    size_t size = ogg.size();

    auto demuxer = std::make_unique<OggDemuxer>();
    demuxer->OnDemuxerFinished([this](const uint8_t* data, int sample_rate, size_t size){
        auto packet = std::make_unique<AudioStreamPacket>();
        packet->sample_rate = sample_rate;
        packet->frame_duration = 60;
        packet->payload.resize(size);
        std::memcpy(packet->payload.data(), data, size);
        PushPacketToDecodeQueue(std::move(packet), true);
    });
    demuxer->Reset();
    demuxer->Process(buf, size);

    // Sentinel rides the FIFO behind the last PCM frame; when it reaches the
    // output task the clip has fully played (see AudioOutputTask). Only enqueue
    // when a completion cb is registered to avoid needless queue traffic.
    if (sound_complete_cb_) {
        auto marker = std::make_unique<AudioStreamPacket>();
        marker->end_of_sound = true;
        PushPacketToDecodeQueue(std::move(marker), true);
    }
}
```

void Application::ArmAckTimer() {
    if (ack_timer_handle_ == nullptr) return;
    esp_timer_stop(ack_timer_handle_);   // idempotent if not running
    esp_timer_start_once(ack_timer_handle_, ACK_DELAY_MS * 1000);

void Application::CancelAckTimer() {

- [ ] **Step 4: Implement `FireAck` (conditions + suppress + play + re-enable)**

In `main/application.cc`:

```cpp
void Application::FireAck() {
    // Fire only for a still-pending turn on a healthy connection.
    if (GetDeviceState() != kDeviceStateListening) return;   // reply already took over
    if (aborted_) return;
    if (protocol_ == nullptr || !protocol_->IsAudioChannelOpened()) return;

    // Pick a random clip, no immediate repeat.
    static const std::string_view kAck[] = {
        Lang::Sounds::OGG_ACK_1, Lang::Sounds::OGG_ACK_2, Lang::Sounds::OGG_ACK_3,
        Lang::Sounds::OGG_ACK_4, Lang::Sounds::OGG_ACK_5,
    };
    constexpr int kAckCount = sizeof(kAck) / sizeof(kAck[0]);
    int idx = esp_random() % kAckCount;
    if (idx == last_ack_index_) idx = (idx + 1) % kAckCount;
    last_ack_index_ = idx;

    // Suppress capture for the clip (stops AFE, drops queued PCM/EOS markers).
    audio_service_.EnableVoiceProcessing(false);
    audio_service_.PlaySound(kAck[idx], [this]() {
        // Runs after the clip's final OutputData(), or on a flush by a reply.
        // Re-enable capture only if the turn is still pending (no reply took over).
        Schedule([this]() {
            if (GetDeviceState() == kDeviceStateListening && !aborted_) {
                audio_service_.EnableVoiceProcessing(true);
            }
        });
    });
}
```

(Verify `protocol_->IsAudioChannelOpened()` exists via `grep -n "IsAudioChannelOpened" main/protocols/protocol.h`; if the accessor differs, use the connected-check already used by `OnAudioChannelClosed`/state transitions.)
