# Waveshare ESP32-C5-Touch-LCD-3.5

微雪 ESP32-C5-Touch-LCD-3.5 开发板，配备 3.5 英寸触摸屏、麦克风、扬声器接口、BF3901 摄像头和电池电源管理，支持语音对话、拍照识别及音量、亮度调节。

## 硬件配置

| 项目 | 配置 |
| --- | --- |
| 主控 | ESP32-C5，16 MB Flash，Quad PSRAM |
| 显示 | ST7796，320 × 480 |
| 触摸 | FT6336 |
| 音频 | ES8311，麦克风输入和扬声器输出 |
| 摄像头 | BF3901，240 × 320 拍照 |
| 电源管理 | AXP2101，电量和充电状态检测 |
| 背光与扩展 IO | CH32V003 |

## 编译与烧录

使用 ESP-IDF v6.0.1 或更新版本，推荐 `release/v6.1` 分支。请先加载 ESP-IDF 开发环境。

```bash
git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32
python scripts/build.py waveshare/esp32-c5-touch-lcd-3.5 --name esp32-c5-touch-lcd-3.5 --language zh-CN
idf.py flash monitor
```

如需指定串口，将最后一条命令改为 `idf.py -p <串口> flash monitor`。

构建脚本会选择对应板型及硬件配置，并生成固件和模型资源。上述中文构建使用“你好小智”唤醒词；语言和唤醒词可通过项目构建选项调整。

使用前，请确认 CH32V003 已烧录本产品的出厂 IO 扩展固件。

## 配网与使用

首次启动时，根据屏幕提示完成 Wi-Fi 配置和设备激活。已保存网络的设备会自动连接；需要更换网络时，可在开机连接 Wi-Fi 阶段单击 BOOT 进入配网。

联网后，说“你好小智”唤醒设备。可使用以下语音操作：

- “音量调到 50”：调节扬声器音量。
- “屏幕亮度调到 80”：调节背光亮度。
- “帮我看看前面有什么”：拍照并识别画面内容。
- “帮我重新配网”：确认后结束当前对话，进入 Wi-Fi 配置模式。

音量和亮度范围均为 0～100。拍照识别及语音控制需要所连接的服务支持设备工具调用；设备断网时，请使用 BOOT 按键进入配网。

## BOOT 按键

| 当前状态 | 单击功能 |
| --- | --- |
| 开机连接 Wi-Fi | 进入配网 |
| 待机 | 开始语音对话 |
| 正在播报 | 打断播报 |
| 正在聆听 | 结束当前对话 |
| 配网界面 | 进入音频测试，再按一次返回配网 |

## 电池与省电

使用电池供电、处于放电状态时，空闲约 60 秒后背光降至 20%，仍可通过语音唤醒。开始对话后恢复保存的亮度，并重新计算空闲时间；空闲累计约 300 秒后自动关机。

电池停止放电或未连接电池时，停用上述省电计时。省电行为遵循项目的 `wifi.sleep_mode` 设置。

本适配提供小智运行所需的屏幕、触摸、音频、摄像头和电源管理功能，不包含出厂测试应用及 SD 卡文件系统功能。
